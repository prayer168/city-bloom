# 築城物語 CityBloom

國小高年級（五、六年級）「永續城市」PBL 用的網頁城市建造模擬遊戲。玩法以 1990 年代城市模擬遊戲為靈感，所有圖像、文字與數值都是原創。

**線上遊玩：https://prayer168.github.io/city-bloom/**

## 目前內容（階段六）

- 道路、電線、住宅／商業／工業分區，建築依需求自動成長
- 七種電廠（燃煤、燃氣、核能、水力、風力、太陽能、儲能），一天四時段供電調度
- 通勤交通、公車站、自行車道、空氣污染與季風
- 碳排放五大來源、綠電比例、永續儀表板、小百科
- 台南氣候平年值與 IPCC AR6 三種暖化情境、都市熱島、冷氣用電、降溫設施
- 颱風、豪雨、熱浪、乾旱、海平面上升；淹水潛勢圖層、災情報告、一個月天氣預報
- 15 種氣候調適設施（滯洪池、堤防、海堤、透水鋪面、再生水廠、避難中心……）與氣候韌性指數
- 原創配景音樂與城市廣播
